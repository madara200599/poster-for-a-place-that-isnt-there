A program (Python 3.13, standard library only) that paints a travel poster for a place that does not exist — **VELMORA**, an island of glowing tides crowned by a crystal lighthouse spire, under a sunset sky over purple mountains and a sparkling sea. It writes one PNG to `/output/entry.png` using a hand-rolled PNG encoder (zlib + struct) and a hand-coded bitmap font for the place name set big into the picture.

Run: `python3 main.py` → writes `/output/entry.png` (800×1000).
